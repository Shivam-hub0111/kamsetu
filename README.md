# KaamSetu Hackathon Prototype
Worker-first local services marketplace.

Demo:
- 7 worker profiles
- Search
- Category filters
- Distance and price filters
- Verified identity/skill badges
- Trust score
- Reviews and experience
- Transparent pricing
- Profile detail
- Booking flow with service, address and time slot
- Booking confirmation

Unique hackathon angle:
1. Worker-owned portable digital reputation
2. Skill verification, not just identity verification
3. Trust score from verification + customer history
4. Nearby-first matching for Tier-2/Tier-3 cities
5. Local-language profiles
6. Transparent starting prices
7. Repeat-customer relationships
8. Future: AI profile creation, skill certificates, UPI, worker earnings dashboard, micro-insurance, route optimisation, offline/low-bandwidth worker app.

Deploy by uploading index.html to Netlify Drop.
